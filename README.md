# Modern Neon Games Collection

A collection of classic arcade games reimagined with a modern **Cyberpunk / Neon** aesthetic. Each game is a standalone HTML file containing all logic, styling, and audio synthesis.

## 🎮 Games List

### 1. Neon Brick Breaker (`Modern Brick Breaker.html`)
A high-energy breakout game featuring:
*   Physics-based ball reflection angles.
*   Dynamic particle explosions and screen shake.
*   Procedural sound effects.

### 2. Neon Pong (`Modern Pong.html`)
The classic 1v1 paddle game against an AI CPU.
*   Glowing trails and impact effects.
*   Adaptive AI difficulty.
*   Glassmorphism UI overlays.

### 3. Neon Tetris (`Modern Tetris.html`)
A fast-paced puzzle game.
*   Full rotation and wall-kick mechanics.
*   Hard/Soft drop support.
*   Time-attack or continuous play modes.

### 4. Neon Match 3 (`Modern Match 3.html`)
A frantic 60-second time-attack puzzle.
*   Match-3 mechanics with gravity and cascading combos.
*   Geometric neon shapes instead of sprites.
*   Chord-based audio feedback for combos.

### 5. Neon Snake (`Modern Snake.html`)
The classic growing serpent game.
*   Smooth grid-based movement with input buffering.
*   Dynamic speed ramping as you eat.
*   Screen shake and "glitch" effects on impact.


## 🛠️ Technology Stack

*   **Core**: HTML5 Canvas + Vanilla JavaScript
*   **Styling**: [Tailwind CSS](https://tailwindcss.com) (via CDN)
*   **Audio**: Web Audio API (No external assets, all real-time synthesis)
*   **Design**: Custom Neon/Glassmorphism theme using CSS shadows and composite operations.

## 🚀 How to Play

Since these are standalone files, no installation or server is required.

1.  Clone the repository:
    ```bash
    git clone https://github.com/YuHyungmin1226/MakeGames.git
    ```
2.  Navigate to the folder and **double-click** any `.html` file to open it in your browser (Chrome/Edge/Firefox recommended).
